# 💊 نظام تذكير الدواء — إصدار رغد

موقع ثابت (static) هدفه واحد: تذكير رغد بموعد دوائها **11:00 صباحاً بتوقيت سوريا**،
بأسلوب نظام رسمي وخطير جداً… ومحتوى مضحك جداً.

بدون backend، بدون قاعدة بيانات، بدون تسجيل دخول. كل الحالة محفوظة في `localStorage`.

---

## التشغيل

```bash
npm install
npm run dev      # http://localhost:4321
```

أوامر أخرى:

| الأمر | الوظيفة |
| --- | --- |
| `npm run build` | يبني الموقع إلى `dist/` |
| `npm run preview` | يعاين نسخة الإنتاج محلياً |
| `npm run check` | فحص أنواع TypeScript وملفات Astro |

```
│  └─ Footer.astro
├─ scripts/
│  ├─ schedule.ts              ⏱ كل حسابات الوقت بتوقيت دمشق — مصدر الحقيقة الوحيد
│  ├─ store.ts                 💾 localStorage: حالة اليوم + السلسلة
│  ├─ copy.ts                  📝 كل النصوص العربية في مكان واحد
│  ├─ notify.ts                🔔 جدول التنبيهات عبر عامل الخدمة

│  ├─ celebrate.ts             🎉 كونفيتي على canvas، بدون مكتبات
│  └─ main.ts                  🔌 يربط الكل: يرسم، يستمع، ينبض كل ثانية
└─ styles/global.css           الـdesign tokens والأزرار والطبقة الأساسية

public/
├─ raghd-dose.ics              تذكير التقويم اليومي
├─ manifest.webmanifest        PWA
├─ sw.js                       عامل الخدمة: تنبيهات + عمل بدون إنترنت
└─ icon-*.png                  أيقونات مولّدة

scripts/
├─ gen-ics.mjs                 يولّد ملف التقويم
└─ gen-icons.mjs               يولّد الأيقونات
```

**قاعدة معمارية واحدة:** `schedule.ts` يُنتج `DoseSnapshot`، و`main.ts` يرسمه.
لا مكان آخر في التطبيق يلمس `Date` أو يكتب في الـDOM.

**المنطقة الزمنية:** الموعد مثبّت على `Asia/Damascus`. كل الحسابات تجري على لحظات
مطلقة (epoch ms) وتُحوَّل إلى ساعة الحائط في دمشق عبر `Intl` فقط — لا عبر توقيت
جهاز الزائرة. إزاحة سوريا ليست مكتوبة في الكود بل تُقرأ من قاعدة بيانات المناطق
الزمنية عند كل لحظة، فيبقى الموقع صحيحاً لو تغيّرت القواعد. حتى تصفير اليوم في
`localStorage` يتبع منتصف ليل دمشق.

## الحالات الأربع

| الوقت | الحالة | ما يظهر |
| --- | --- | --- |
| قبل 11:00 بتوقيت سوريا | `before` | عدّ تنازلي حي + "لسا بدري، خدي راحتك." |
| 11:00 → 11:05 | `due` | "رغد… الساعة صارت 11." + زرّا الإجراء |
| بعد 11:05 | `late` | "الدواء عم يستناك" + عدّاد تصاعدي + "متأخرة ٢٣ دقيقة" |
| بعد التسجيل | `taken` | ✅ شاشة النجاح + كونفيتي + عدّ لجرعة الغد |

اللوحة كلها تتلوّن حسب الحالة (بنفسجي → برتقالي → أحمر → أخضر) عبر تبديل
متغيّرات CSS على `body[data-phase]` — لا CSS مكرّر لكل حالة.

**التخزين:** مفتاح `raghd:dose:v1` يحمل `dayKey` بتوقيت دمشق. عند فتح الموقع
في يوم جديد لا يطابق المفتاح، فتُصفَّر الحالة تلقائياً. `raghd:streak:v1` يحفظ
عدد الأيام المتتالية.

## 🔔 التذكير على الموبايل

الجدول واحد في الطريقتين: **من 10:55 تنبيه كل دقيقة حتى 11:00** بتوقيت سوريا،
أي ست تنبيهات يومياً.

### 1) التقويم — `public/raghd-dose.ics` (الأساس)

ملف iCalendar يولّده [`scripts/gen-ics.mjs`](scripts/gen-ics.mjs). تضيفه رغد مرة
واحدة إلى تقويم الهاتف، فيصير **الهاتف نفسه** هو من يطلق التنبيه: يشتغل
والمتصفح مغلق، والشاشة مطفية، وبدون إنترنت.

- `VTIMEZONE` صريح لـ`Asia/Damascus` بإزاحة ‎+0300‎ (سوريا ألغت التوقيت الصيفي
  في 2022-10-28)، فلا يتبع الموعد توقيت هاتفها لو سافرت.
- `RRULE:FREQ=DAILY` بلا نهاية.
- ستة `VALARM` منفصلة عند ‎−5 −4 −3 −2 −1 0‎ دقيقة. استُخدمت منبّهات منفصلة بدل
  `REPEAT`/`DURATION` لأن دعم `REPEAT` متفاوت بين تقويم آبل وGoogle.
- الملف يلتزم بـRFC 5545: أسطر CRLF، وطيّ عند 75 بايت دون كسر محرف UTF-8.

### 2) تنبيه المتصفح — `src/scripts/notify.ts` (إضافة)

نفس الجدول، لكنه يعمل **فقط والصفحة مفتوحة** ولو في الخلفية.

- التنبيه يمرّ عبر `ServiceWorkerRegistration.showNotification()` لا عبر
  `new Notification()`، لأن الأخير يرمي استثناءً على أندرويد/كروم.
- `raghd:notified:v2` يسجّل أي التنبيهات الستة أُرسلت اليوم، فلا يتكرّر شيء بعد
  إعادة التحميل.
- عند فتح الصفحة بعد فوات عدة تنبيهات، يُرسل **الأحدث فقط** بدل ستة دفعة واحدة.
- إعادة المزامنة عند `visibilitychange` و`focus`، لأن مؤقتات الخلفية على
  الموبايل تُخنق أو تُقتل.
- يتوقّف الجدول فوراً بمجرد تسجيل الجرعة.

> **لماذا لا يوجد Web Push؟** التنبيه والمتصفح مغلق تماماً يحتاج Web Push، وWeb
> Push يحتاج سيرفراً يرسل الدفعة في وقتها — والمشروع بلا backend عمداً. ولا يوجد
> API قياسي لجدولة تنبيه محلي مستقبلي (اقتراح Notification Triggers لم يصل إلى
> أي متصفح مستقر). لذلك التقويم هو الحل الصحيح لا حلاً بديلاً.

### إلغاء الإشعارات

قسم التذكير يشرح للمستخدمة بوضوح أن الموقع يرسل إشعاراً كل دقيقة بدءاً من خمس
دقائق قبل الموعد، ويعطيها طريقتين للتواصل مع إبراهيم لإلغائها أو تغيير الموعد:
واتساب (‎+971 52 569 1003‎، برسالة مُعبّأة مسبقاً) وإنستغرام
([‎@znad_0‎](https://www.instagram.com/znad_0)).

### 🎵 الموسيقى

وضعان، يُختار الوضع **وقت البناء** حسب وجود الملف:

**١) ملف محلي — وهذا الوضع الفعلي.** الأغنية «جيتني صدفة» لأحمد علوي مودَعة في
`public/music/track.m4a`، فالمشغّل عنصر `<audio>`: موسيقى خلفية حقيقية بلا مشغّل
مرئي، تتكرّر تلقائياً، بصوت خافت (‎0.35‎) مع تلاشٍ تدريجي عند البدء. أي امتداد من
`mp3`/`m4a`/`ogg`/`wav` باسم `track` يُلتقط تلقائياً وقت البناء.

**٢) يوتيوب (الاحتياط).** إن حُذف الملف، نضمّن المشغّل الرسمي. لكن معرّف الفيديو
المضمّن حالياً هو للأغنية السابقة «كل القصايد» لمروان خوري ويحتاج تحديثاً — راجع
[`public/music/README.md`](public/music/README.md).

**عن التشغيل التلقائي:** كل المتصفحات تمنع الصوت التلقائي قبل أي تفاعل. هذه سياسة
متصفح لا قيد كود، ولا توجد حيلة تتجاوزها. لذلك نحاول التشغيل فوراً، وإن رُفض
نُسلّح أول `pointerdown`/`touchstart`/`keydown`/`scroll`/`wheel` فتبدأ الموسيقى
عندها — عملياً: تشتغل لوحدها بمجرد أن تلمس رغد الصفحة. الزر يعرض «المسي الشاشة»
في هذه الأثناء.

إن أوقفتها، يُحفظ الاختيار في `raghd:music:v1` فلا نُشغّلها في الزيارة القادمة.

## 📊 إحصائيات الزوار

**GitHub Pages لا يوفّر أي إحصائيات.** و`Insights → Traffic` في المستودع يقيس
مشاهدات صفحة المستودع على github.com، **لا زوار الموقع المنشور** — يبقى صفراً
مهما زار الموقع من زار.

لذلك يحتاج الأمر أداة خارجية. الإعداد كله في
[`src/analytics.config.ts`](src/analytics.config.ts).

**المفعَّل الآن:** عدّاد `hits.sh` في التذييل — بلا تسجيل، يعمل فوراً، ويعرض
«اليوم / الإجمالي». حدوده صريحة: يعدّ **مرات فتح الصفحة** لا الزوار الفريدين،
ولا يعطي بلداناً ولا مصادر، ويعتمد على خدمة مجانية من طرف ثالث.

**للوحة حقيقية** املأ حقلاً واحداً من الحقلين أدناه وابنِ:

| الأداة | الحجم | مجاني | كوكيز |
| --- | --- | --- | --- |
| **GoatCounter** (موصى به) | ‎~3.5 KB‎ | نعم، للاستخدام الشخصي | لا |
| **Cloudflare Web Analytics** | ‎~5 KB‎ | نعم، بلا حدّ | لا |

كلاهما بلا كوكيز وبلا بيانات شخصية، فلا حاجة إلى شريط موافقة. ولا يُحمَّل أي
سكربت ما دام الملف فارغاً — الموقع بلا أي تتبّع افتراضياً.

عامل الخدمة يتجاهل كل النطاقات الخارجية عمداً، حتى لا يعترض نداءات العدّ.

## 🥚 البيض المخفي

1. **انقري حبة الدواء** في البطاقة — رسائل عند النقرة ٣ و٥ و٨، ومطر حبوب عند ١٢.
2. **"لسا شوي"** — الرسالة تتصعّد مع كل ضغطة، حتى ٦ مستويات.
3. **لجنة الدواء العليا** — ٣ نقرات على كلمة «ساعة / دقيقة / ثانية» تحت العدّاد،
   أو `Shift + L`. تفتح لوحة تحاكي الوقت (وهي أيضاً أداة اختبار الحالات).
4. **اتركي التبويب** وأنتِ متأخرة — عنوان الصفحة يناديكِ.
5. **انسخي أي نص** من الصفحة — النظام يعلّق.
6. **حبة الفوتر** — مطر حبوب + تعليق.

## النشر على GitHub Pages

الملف `.github/workflows/deploy.yml` جاهز ويعمل تلقائياً:

1. ارفعي المشروع إلى مستودع على GitHub.
2. من **Settings → Pages → Build and deployment → Source** اختاري **GitHub Actions**.
3. ادفعي إلى `main` — سيبني وينشر تلقائياً.

الـworkflow يستخدم `actions/configure-pages` لمعرفة مسار النشر الحقيقي ويمرّره
كـ`BASE_PATH`، لذا تعمل كل المسارات في الحالتين:

- **موقع مستخدم** `username.github.io` → المسار `/`
- **موقع مشروع** `username.github.io/repo` → المسار `/repo/`

> `public/.nojekyll` موجود ومهم: بدونه يتجاهل GitHub Pages مجلد `_astro/`
> (لأن اسمه يبدأ بشرطة سفلية) فتضيع كل ملفات CSS وJS.

للبناء يدوياً لموقع مشروع:

```bash
BASE_PATH=/repo-name/ npm run build
```

## ما تم اختباره

اختُبر المبني الفعلي في Chrome عبر Puppeteer:

- الحالات الأربع (قبل / عند / بعد الموعد / تم الأخذ) — عبر محاكاة ساعة دمشق
- **تثبيت المنطقة الزمنية:** عدّاد متطابق عبر ٦ توقيتات أجهزة من UTC+14 إلى UTC−11،
  ومطابق لساعة دمشق المحسوبة باستقلال عن التطبيق
- مجموعة أزرار واحدة ظاهرة في كل حالة، ولوحتا live/success متنافيتان
- بدون تمرير أفقي على ‎320 / 390 / 834 / 1440‎ بكسل
- دورة كاملة: تأجيل ×٣ → تصعيد الرسائل → أخذ الجرعة → كونفيتي → حفظ →
  إعادة تحميل → الحالة محفوظة → انقلاب اليوم يصفّر تلقائياً
- البيض المخفي، ولوحة اللجنة (فتح/محاكاة/إغلاق بـ Esc)
- `prefers-reduced-motion` — كل المحتوى يبقى ظاهراً وتتوقف الحركة
- خدمة الموقع تحت مسار فرعي `/raghad/` بدون أي طلب فاشل
- ملف `.ics`: ١٦ فحصاً بنيوياً (CRLF، توازن BEGIN/END، المنطقة الزمنية،
  التكرار، المنبّهات الستة، صيغة المثنّى العربية)
- عامل الخدمة يُسجَّل ويتحكّم، والـmanifest وأيقوناته الثلاث تُحمَّل ‎200‎
- تنبيه حقيقي يُقرأ من `registration.getNotifications()` بنصّه العربي واتجاه RTL،
  ولا يتكرّر بعد إعادة التحميل
- **صفر أخطاء console، صفر أخطاء أنواع**

## ملاحظات

- الخط **IBM Plex Sans Arabic** من Google Fonts مع `display=swap` ومكدّس بديل
  (`Tajawal` → `Segoe UI` → system-ui).
- الأرقام في العدّاد لاتينية ومُثبّتة العرض (`tabular-nums`) — الأرقام العربية

- لتغيير الموعد: عدّلي `DOSE_HOUR` و`DOSE_MINUTE` في
  [`src/scripts/schedule.ts`](src/scripts/schedule.ts).
