# 🎵 مكان ملف الأغنية

ضع ملف الأغنية هنا باسم `track` مع أي امتداد من: `mp3` · `m4a` · `ogg` · `wav`

```
public/music/track.mp3
```

بمجرد وجوده، يلتقطه البناء تلقائياً ويتحوّل المشغّل من مشغّل يوتيوب المضمّن
إلى عنصر `<audio>` حقيقي: موسيقى خلفية بلا مشغّل مرئي، تبدأ عند أول لمسة،
وتتكرّر تلقائياً.

إن لم يوجد الملف، يعود المشغّل تلقائياً إلى مشغّل يوتيوب الرسمي.

## ⚠️ تنبيه حقوق النشر

هذا المستودع **عام**. رفع تسجيل تجاري محمي بحقوق النشر عليه يُعدّ نشراً غير
مرخّص، ويعرّض حساب GitHub لبلاغ إزالة (DMCA).

الخيارات الآمنة:

1. **اجعل المستودع خاصاً** وانشر على Cloudflare Pages أو Netlify (كلاهما يدعم
   المستودعات الخاصة مجاناً).
2. **أبقِ مشغّل يوتيوب** — الوضع الافتراضي، وهو مرخّص بالكامل.
3. استخدم مقطعاً تملك حقوقه أو موسيقى حرة الاستخدام.

هذا المجلد نفسه لا يحوي أي ملف صوتي، ومتجاهَل في `.gitignore` تحسّباً.
